## 🎯 Strategic Principles

### 1. ServiceNow-First Design
* **Rule:** If ServiceNow provides an Out-Of-The-Box (OOTB) capability, **USE SERVICENOW OOTB**.
* Use native ServiceNow forms, lists, workspaces, related lists, and roles.
* Only customize where AppForge delivers transformative speed and policy-as-code automation.

### 2. Outcome-Based Business Templates
Customers buy business solutions, not technical database tables:
* **Business Outcomes:** *Employee Onboarding*, *Vendor Management*, *Customer Service Hub*, *IT Asset Procurement*, *Project Intake & Governance*, *Contract Lifecycle*.
* **Outcome Promise:** *"Get a complete, certified business application in ServiceNow in 2 minutes."*

### 3. Configuration Over Customization
* Enable business teams to configure forms, approval steps, SLAs, and notification rules without editing generated code.
* Guarantees seamless, zero-breakage upgrades from `v1.0.0` to `v1.1.0+`.

### 4. Human-Centric Terminology Translation

| Internal Technical Concept | Customer-Facing ServiceNow Term |
| :--- | :--- |
| *Execute AppForge Package Manifest* | **Install Application** |
| *Initiate Deployment State Transition* | **Deploy** |
| *Package Integrity Verification* | **Verified (✓ Signed & Trusted)** |
| *Declarative 5-Layer Definition* | **Application Configuration** |
| *Tenant Isolation Context Validation* | **Organization Workspace** |
| *Compensating Snapshot Rollback* | **Restore Previous Version** |

## 🏆 The Million-Dollar Company Test

Every new feature must satisfy these 6 criteria:
1. **Customer Value:** Does this save the customer tangible time and money?
2. **Implementation:** Does this eliminate ServiceNow configuration friction?
3. **Usability:** Can a ServiceNow administrator understand it in under 60 seconds?
4. **Revenue:** Does this drive subscriptions, usage, or partner expansion?
5. **Scalability:** Can this identical template be deployed to 1,000 customers repeatedly?
6. **Upgradeability:** Can customers upgrade without breaking existing business data?
