# AppForge User Guide

Welcome to AppForge. This guide explains how to create, configure, and monitor applications within your ServiceNow environment.

---

## 🧭 Navigation Overview
The AppForge Studio Workspace consists of 7 simplified views:
1. **🏠 Home Dashboard:** System summary, health metrics, and recent releases.
2. **⚡ Create Application:** Template-first application synthesis.
3. **📦 My Applications:** One-page application status, versions, and drift monitoring.
4. **🚀 Deploy & Release:** Preflight verification and one-click deployment.
5. **📂 Import Existing App:** Reverse-engineering wizard for update sets.
6. **💼 Portfolios & Demand:** Strategic budget tracking and demand intake.
7. **🩺 Health & Admin:** Instance diagnostic scans and configuration.

---

## ⚡ Creating an Application
1. Click **Create Application**.
2. Select a template matching your business workflow (Employee Onboarding, Vendor Management, IT Request).
3. Fill in the **Name** and **Business Owner**.
4. Click **Create Application 🚀**.

---

## 🔍 Monitoring Drift & Rollback
If an unauthorized change occurs in a sub-production instance:
1. Navigate to **My Applications**.
2. If drift is detected, click **Rollback**.
3. AppForge automatically restores the exact verified schema.
