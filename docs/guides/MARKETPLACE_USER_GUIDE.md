# AppForge Marketplace User Guide

**Release:** v0.20.0  
**Target:** Implementation Teams & Platform Administrators  

---

## 🧭 The Marketplace Model

The AppForge Marketplace transforms solution deployment into a native ServiceNow plugin-like experience:

```text
Browse Solution ──> Inspect Details ──> Install ──> Auto-Generated Module ──> Configure ──> Use
```

---

## 🛒 Available Solutions
1. **Bulk Catalog Automation (Installed & Ready):** Single-page bulk catalog import, variables builder, and multi-stage after-submit fulfillment orchestration.
2. **ITSM Accelerator (Coming Soon):** Pre-configured incident, problem, change, and major incident workflows.
3. **CSM Accelerator (Coming Soon):** Customer case intake and SLA escalation hub.
4. **CRM Accelerator (Coming Soon):** SaaS accounts, contacts, and subscriptions manager.
5. **FSM Accelerator (Coming Soon):** Field service dispatching and work order scheduling.
6. **SPM Accelerator (Coming Soon):** Strategic portfolio management and capital budgeting.
