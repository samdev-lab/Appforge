# AppForge v0.20 Master Platform & Marketplace Guide

**Platform Version:** `v0.20.0`  
**Core Mission:** One-Click ServiceNow Solution Marketplace & No-Code Implementation Accelerator.

---

## 🌟 Strategic Product Pillars

1. **ServiceNow Native Experience:** Runs natively inside ServiceNow using standard UI themes, `sc_cat_item`, `item_option_new`, `sc_task`, `sc_req_item`, and Flow Designer.
2. **One-Click Installation Engine:** Automated 22-step deployment pipeline with license validation, dependency checking, and cryptographic verification.
3. **Internal vs Customer RBAC Separation:**
   * **AppForge Team Workspace:** Customer CRM, implementation stages, health scores, subscriptions, and deployments.
   * **Customer Self-Service:** Browse solutions, 1-click install, configure via Bulk Catalog Manager, and submit requests.
4. **Commercial Pricing Tiers:**
   * **Community (Free):** Up to 50 catalog items.
   * **Professional ($499/mo):** Up to 500 catalog items with standard fulfillment.
   * **Enterprise ($1,499/mo):** Unlimited catalog items with advanced flow orchestration and 24/7 SLA.
