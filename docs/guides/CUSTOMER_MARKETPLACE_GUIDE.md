# AppForge Customer Marketplace Guide

A simple, non-technical guide for browsing, installing, and upgrading ServiceNow applications.

---

## 🛒 Finding & Installing Applications

1. Open the **AppForge Template Marketplace** from the left navigator or Studio Workspace.
2. Select a category (HR, ITSM, CSM, Vendor Management, Operations).
3. Review the included tables and modules.
4. Click **Install 🚀**.
5. Once complete, click **Open Application ↗** to begin creating records immediately.
