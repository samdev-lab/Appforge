# AppForge Customer & End-User Application Guide

For end users interacting with applications installed by AppForge.

---

## 🧭 Using Your Generated Application

Applications installed via AppForge operate as standard native ServiceNow applications:

* **Finding Your App:** Open the ServiceNow left filter navigator and search for your application name (e.g., *Employee Onboarding* or *Vendor Management*).
* **Creating Records:** Click on any module (e.g. *Onboarding Requests*) to view list data or click *New* to open the form.
* **Approvals & Workflows:** Business rules and Four-Eyes release gates execute automatically in the background.
* **No Studio Access Needed:** End users do NOT need access to the AppForge control plane or developer workspace.
