# AppForge Template Installation Guide

How to browse, select, and install enterprise application templates in ServiceNow.

---

## ⚡ 1-Click Installation Workflow

1. Navigate to the **Template Catalog** in AppForge Studio:
   👉 **`https://<your-instance>.service-now.com/x_1805046_app_fo_0_workspace.do`**
2. Filter templates by category (**HR**, **ITSM**, **CSM**, **Vendor Management**, **Operations**).
3. Click **Details** to review included modules, tables, and security policies.
4. Click **Install 🚀**.
5. Specify the target **Application Name** and click **Review & Install**.
6. Once installation completes, click **Open Application ↗** to navigate directly to your live application!
