# AppForge Documentation — Security

See primary documentation in [docs/security/README.md](../../docs/security/README.md).

## Core Security Baseline
- **Role Strategy**: `x_appforge.admin`, `x_appforge.developer`, `x_appforge.user`
- **Closed Security Posture**: Closed by default; explicitly scoped ACLs required for all operations.
- **Zero Global Modifications**: No global scope edits.
