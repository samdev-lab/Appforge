# AppForge Documentation — Application Factory Core

See primary documentation in [docs/application-factory/README.md](../../docs/application-factory/README.md).

## Core Provisioning Pipeline
- **Declarative Definitions**: `x_appforge_application_definition`
- **Factory Runs**: `x_appforge_factory_run`
- **Granular Operations**: `x_appforge_factory_operation`
- **Dry-Run REST API**: `POST /api/x_appforge/factory/plan`
- **Execution REST API**: `POST /api/x_appforge/factory/execute`
