# AppForge Documentation — Experience Factory

See primary documentation in [docs/experience-factory/README.md](../../docs/experience-factory/README.md).

## Core Experience Provisioning Layer
- **Form Registries**: `x_appforge_form`, `x_appforge_form_section`, `x_appforge_form_field`
- **List & View Registries**: `x_appforge_list`, `x_appforge_list_field`, `x_appforge_view`
- **Navigation & Related Lists**: `x_appforge_navigation`, `x_appforge_related_list`
- **Platform UI Tables**: `sys_ui_form`, `sys_ui_list`, `sys_ui_view`, `sys_app_module`
- **Dry-Run REST API**: `POST /api/x_appforge/experience/plan`
- **Execution REST API**: `POST /api/x_appforge/experience/execute`
