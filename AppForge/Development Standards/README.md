# AppForge Documentation — Development Standards

See primary documentation in [docs/development-standards/README.md](../../docs/development-standards/README.md).

## Key Naming Conventions Summary
- **Scope Prefix**: `x_appforge`
- **Tables**: `x_appforge_<table_name>`
- **Fields**: `u_<field_name>` or scope prefix
- **Script Includes**: `AppForge<Name>`
- **Roles**: `x_appforge.<role_name>` (`x_appforge.admin`, `x_appforge.developer`, `x_appforge.user`)
